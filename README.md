## 概述

Eword 是一款完全离线的 Android 背单词应用，词库取四六级历年真题（2015–2026 年）。

它与常见背单词应用的关键差别，在于**释义的取材方式**：释义不从词典转录，而是取自该词在某道真题句子中实际表达的含义。词在卷面那句话里作什么意思，释义就写什么意思；那句话连同官方译文收在卡片的「例句」一节，出处标注到「哪年哪月第几套」。记一个词的同时，也记住了它在真题里怎么用。

词库与应用分离发布：安装包里不含任何词条数据，词包（`.ewp`）单独下载后导入。二者版本独立演进，更新词包无需重装应用。

## 功能

### 四阶段记忆闭环

| 阶段 | 内容 | 判定与去向 |
|---|---|---|
| 识记 | 按单元逐词推进，完整词条一次性铺开 | 「记住了」进入温习一；「没记住」留在本单元，本单元过完可再走一轮 |
| 温习一 | 只显示单词，先主动回忆 | 「记住了」进入温习二；「没记住」留在温习一 |
| 温习二 | 沉淀温习一中想起来的词，再巩固一轮 | 「记住了」进入最终页面；「没记住」退回温习一 |
| 最终页面 | 已彻底记住的词在此成册 | 可把某个词退回「未识记」，重新走一遍识记流程 |

回忆环节给出两条路径，对应「想起来了没有」的两种诚实回答：

- **逐条展开例句** —— 只给英文原句，读到「例句意思」即记为「没记住」。这是靠例句提示才想起来的。
- **显示完整答案（核对用）** —— 一次展开释义，核对之后由你自己判定。

**看过释义之前，「记住了」不可点击**，免得凭模糊印象蒙过去；例句逐条展开时先只给英文，看过释义之后才补上中文译文。

识记页与温习页的判定按钮都完全对称：误点「记住了」之后用「上一个」退回该词，改点「没记住」即生效，反之亦然。

温习页的「上一个」会把该词复位成待温习（在温习二里退回的词因此回到温习一），并要求重新看过释义才能再判定。本单元过完后那一屏也留着「上一个」，最后一张判错同样能退回去改。

### 词条卡片

一张卡片呈全一个词的全部信息，顺序固定：

```
单词 → 音标 · 级别 · 真题句数 → 词义 → 单词变形 → 形近词 → 近义词 → 短语搭配 → 例句
```

- **词义按来源分组** —— 真题里出现过的义项归入「真题」，真题未涉及、按词典补充的归入「词典补充」。哪些考过、哪些只需了解，一眼可辨。单词在真题里往往只用一个意思出现，只收真题义项会让释义偏窄（`bank` 只剩「银行」），因此每个词都补到能覆盖备考所需的常用义项。
- **真题义项是判读出来的，不是抄来的** —— 卷面上出现过的义项，按原句与同卷官方译文逐条定出来；词典里查得到、卷面却没出现过的义项不往「真题」里放。释义从译文里推出来，就**可以自己回原文核对**：该义项在卷面里的那句话连同译文，就在这张卡片的「例句」一节，出处标到套（`2016.12 第3套`）。
- **单词变形只列真题原文里出现过的形态**，逐一标出变形名称；长词不会硬凑比较级，名词也不会硬塞动词形式。
- **形近词与近义词可直接点击跳转**，进入另一个词的详情页；返回后停在原卡片、原单元与原进度。
- **短语搭配与例句可在设置中整体隐藏**，只留单词与词义。

同一份排版在识记卡片、温习揭示与词条详情页三处复用，外观与顺序完全一致。

### 词本管理

- 可同时导入多个词包，同一时间只启用一个；启用哪一个，识记与温习就以哪一个为准。
- 支持按单元浏览、按单词搜索、打乱单词顺序与恢复原顺序。
- 可单独清空某个词本的学习进度，也可删除词本。**删除词本不动学习进度** —— 以后重新导入同一词本，先前学到哪里还在。
- 学习进度按「词包 + 词条」记录，导入新版本词包、停用或切换词本都不受影响。

### 设置

- **每单元单词数**（默认 52，可调 5–200）：识记、温习、我的单词本三处共用。更改时应用会提示：全部词条的单元编号将重排，已学状态保留，但每个单元「上次学到第几个词」会按新划分重算。
- **自动发音**：单词出现时自动播放。
- **显示短语搭配**、**显示例句**：控制卡片内容的详略。

所有改动先进入草稿，确认保存后才生效；带着未保存的改动返回会先询问。

### 版本与更新

应用与词包分别更新，互不影响：换用新版词包不必重装应用，学习进度照旧保留。设置里会列出应用版本与**当前启用词本**的词包版本，便于比对；手上某个词本是哪一版，在「我的单词本」里也能看到。

## 安装

1. 在[最新版 Release](https://github.com/XxuCyprus/Eword/releases/latest) 下载 `Eword-v4.3.0.apk` 并安装（首次安装需在系统设置中允许安装未知来源应用）。
2. 打开[全部 Releases](https://github.com/XxuCyprus/Eword/releases)，找到词包那一版（标题形如 `Eword CET4-6 Pack v21`），下载 `Eword-CET4-6-Pack-v21.ewp`。词包与应用的 Release 分开列出，因此词包不在「最新版」页面上，需要到列表里找。
3. 打开 Eword →「我的单词本」→「导入单词本」→ 选择刚下载的 `.ewp`，等待导入完成。

> 需要 **Android 11（API 30）及以上**。词包必须单独下载导入，应用内不含词条数据。
> 词包 v21 需要**应用 4.3.0 及以上**（v21 与 4.3.0 配套发布）；
> 应用版本偏低时，导入界面会提示先升级应用，不会装上一个与界面版本对不上的词包。

## 隐私与权限

- **不申请任何权限，也不联网。** 没有网络权限，它就没有能力把数据发出去。例句、译文、音标与音频全部随词包离线提供。
- **数据仅存本机。** 词包解压至应用私有目录，学习进度存于本地，不参与系统备份与换机迁移。
- **卸载即清空。** 学习进度随卸载一并删除。

## 数据来源

例句、中文译文与短语搭配取自四六级历年真题原文及官方参考译文，逐条核对过中英是否对应——**一条英文只配它自己那句的中文**，配不实的宁可空着；真题之外补充的义项取自 ECDICT（MIT 许可的英汉词典，`github.com/skywind3000/ECDICT`），按词条精确匹配取值；音标取自 CMU 发音词典（美式 IPA），发音为随词包分发的离线音频。每词至多 5 条例句。

各类内容的成色：

| 内容 | 说明 |
|---|---|
| 词义 | 按来源分成两组：真题里出现过的标「真题」，真题之外按词典补充的标「词典补充」 |
| 义项依据 | 真题义项按卷面原句与同卷官方译文逐条判读；该原句收在「例句」一节，出处标到套（`2016.12 第3套`） |
| 例句 | 取自真题原文，中英逐条对应，且**逐字回卷面核过**；按义项铺开，同一个词的不同意思各有各的例句；核不出出处的例句不标注出处 |
| 短语搭配 | 在真题里跨卷稳定出现的搭配 |
| 单词变形 | 真题原文里真实出现过的形态 |
| 形近词 | 拼写相近、容易认错的词；同族派生词（`arrival` 与 `arrive`）与变形形态（`abandoned` 之类）不在此列，它们属于「单词变形」 |
| 近义词 | 主要义项相同的词（并参照 WordNet 同义词集） |
