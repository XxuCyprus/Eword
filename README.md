## 概述

Eword 是一款完全离线的 Android 背单词应用，词库取四六级历年真题（2015–2026 年）。

它与常见背单词应用的关键差别，在于**释义的取材方式**：释义不从词典转录，而是取自该词在某道真题句子中实际表达的含义。每一条释义都锚定它在真题里的具体用法，并附上该句原文与官方参考译文，出处标注到「哪年哪月第几套」。记一个词的同时，也记住了它在真题里怎么用。

由此确立一条贯穿整个项目的数据准则：

> 凡声称取自真题的内容，都必须能在真题原文中逐条核实；核实不了的宁可留空，不作推测。

词库与应用分离发布：安装包里不含任何词条数据，词包（`.ewp`）单独下载后导入。二者版本独立演进，更新词包无需重装应用。

## 功能

### 四阶段记忆闭环

| 阶段 | 内容 | 判定与去向 |
|---|---|---|
| 识记 | 按单元逐词推进，完整词条一次性铺开 | 「记住了」进入温习一；「没记住」留在本单元，本单元过完可再走一轮 |
| 温习一 | 只显示单词，先主动回忆 | 「记住了」进入温习二；「没记住」留在温习一 |
| 温习二 | 沉淀温习一中想起来的词，再巩固一轮 | 「记住了」进入最终页面；「没记住」退回温习一 |
| 最终页面 | 已彻底记住的词在此成册 | 可把某个词退回「未识记」，重新走一遍识记流程 |

回忆环节给出两条路径，对应「想起来了没有」的两种诚实回答：

- **逐条展开例句** —— 只给英文原句，读到「例句意思」即记为「没记住」。这是靠例句提示才想起来的。
- **显示完整答案（核对用）** —— 一次展开释义，核对之后由用户自行判定。

**看过释义之前，「记住了」不可点击**，不让用户凭模糊印象蒙过去；例句逐条展开时先只给英文，看过释义之后才补上中文译文。

识记页与温习页的判定按钮都完全对称：误点「记住了」之后用「上一个」退回该词，改点「没记住」即生效，反之亦然。

温习页的「上一个」会把该词复位成待温习（在温习二里退回的词因此回到温习一），并要求重新看过释义才能再判定。本单元过完后那一屏也留着「上一个」，最后一张判错同样能退回去改。

### 词条卡片

一张卡片呈全一个词的全部信息，顺序固定：

```
单词 → 音标 · 级别 · 真题句数 → 词义 → 单词变形 → 形近词 → 近义词 → 短语搭配 → 例句
```

- **词义按来源分组** —— 真题里出现过的义项归入「真题」，真题未涉及、按词汇大纲补充的归入「真题补充」。哪些考过、哪些只需了解，一眼可辨。单词在真题里往往只用一个意思出现，只收真题义项会让释义偏窄（`bank` 只剩「银行」），因此每个词都补到能覆盖备考所需的常用义项。
- **单词变形只列真题原文里出现过的形态**，逐一标出变形名称；长词不会硬凑比较级，名词也不会硬塞动词形式。
- **形近词与近义词可直接点击跳转**，进入另一个词的详情页；返回后停在原卡片、原单元与原进度。
- **短语搭配与例句可在设置中整体隐藏**，只留单词与词义。

同一份排版在识记卡片、温习揭示与词条详情页三处复用，外观与顺序完全一致。

### 词本管理

- 可同时导入多个词包，同一时间只启用一个；启用哪一个，识记与温习就以哪一个为准。
- 支持按单元浏览、按单词搜索、打乱单词顺序与恢复原顺序。
- 可单独清空某个词本的学习进度，也可删除词本。**删除词本不动学习进度** —— 以后重新导入同一词本，先前学到哪里还在。
- 学习进度按「词包 + 词条」记录，导入新版本词包、停用或切换词本都不受影响。

### 设置

- **每单元单词数**（默认 52，可调 5–200）：识记、温习、我的单词本三处共用。更改时应用会提示：全部词条的单元编号将重排，已学状态保留，但每个单元「上次学到第几个词」会按新划分重算。
- **自动发音**：单词出现时自动播放。
- **显示短语搭配**、**显示例句**：控制卡片内容的详略。

所有改动先进入草稿，确认保存后才生效；带着未保存的改动返回会先询问。

### 版本与兼容

应用与词包各自独立发版，设置中同时列出应用版本与**当前启用词本**的词包版本，便于比对。

词包可在自己的清单里声明所要求的**最低应用版本**；版本不够时，应用在导入之前就提示升级应用，而不是让功能在界面上莫名缺失。

## 安装

1. 在[最新版 Release](https://github.com/XxuCyprus/Eword/releases/latest) 下载 `Eword-v4.1.2.apk` 并安装（首次安装需在系统设置中允许安装未知来源应用）。
2. 打开[全部 Releases](https://github.com/XxuCyprus/Eword/releases)，找到词包那一版（标题形如 `Eword CET46 Pack v15`），下载 `Eword-CET46-Pack-v15.ewp`。
3. 打开 Eword →「我的单词本」→「导入单词本」→ 选择刚下载的 `.ewp`，等待导入完成。

> 系统要求 **Android 11（API 30）及以上**。
> 应用与词包**各发各的 Release**：应用那一版标 Latest，词包不标，因此词包不出现在「最新版」页面上，需要到 Releases 列表中查找。二者分别更新，换用新版词包不必重装应用；手上词包的版本号，在「我的单词本」与设置里都能看到。
> 安装包约 2 MB，词包约 67 MB。词包必须单独下载导入，应用内不含词条数据。
> 导入需要数十秒，期间请勿退出应用 —— 中途退出会留下不完整的词本。

## 隐私与权限

- **不申请任何有效权限。** 应用清单中唯一一条 `uses-permission` 是 AndroidX 自动注入的
  `DYNAMIC_RECEIVER_NOT_EXPORTED_PERMISSION`（签名级，只供应用自己注册广播，系统不向用户
  提示，也不接触任何数据）。没有网络权限，它就没有能力把数据发出去。例句、译文、音标与
  音频全部随词包离线提供。
- **数据仅存本机。** 词包解压至应用私有目录，学习进度存于本地；系统备份与数据迁移已整体
  关闭（`allowBackup=false` 并排除全部抽取范围）。
- **卸载即清空。** 学习进度随卸载一并删除，不会从系统备份中恢复。

## 数据来源与质量准则

例句、中文译文与短语搭配取自四六级历年真题原文及官方参考译文，逐条核验中英是否对应；真题之外补充的义项取自 ECDICT（MIT 许可的英汉词典，`github.com/skywind3000/ECDICT`），只按词条精确匹配，取舍规则见下表；音标取自 CMU 发音词典（美式 IPA），发音为随词包分发的离线音频。当前词包收录约一万词，每词至多 5 条例句。

各项内容的收录判据：

| 内容 | 判据 |
|---|---|
| 词义 | 按来源分组：真题里出现过的标「真题」，真题之外按词汇大纲补充的标「真题补充」 |
| 例句 | 必须能在真题原文中逐条核实、且中英对应；核实不了的宁可留空 |
| 短语搭配 | 只收在真题里跨卷稳定出现的搭配 |
| 单词变形 | 只收真题原文里真实出现过的形态 |
| 形近词 | 只收不同族、拼写确实相近的词。同族派生词（`arrival` 与 `arrive`）与变形形态（`abandoned` 之类）不算，它们属于「单词变形」 |
| 近义词 | 共同义项必须落在**双方各自的主要义项**里（并参照 WordNet 同义词集）；只有一方在冷僻义项上撞车的不收 |

> 真题原文与官方译文的版权归原出版方所有，本项目仅作学习用途。

## 版本与发布

应用与词包分别打标签、分别出 Release，互不牵连：

| 产物 | 标签 | Release 标记 |
|---|---|---|
| 应用 | `app-v4.1.2` | Latest |
| 词包 | `pack-cet46-v15` | 不标 Latest |

词包的 `packId` 固定为 `cet46`，数据每更新一次版本号递增一次；所需的最低应用版本由词包清单自己声明。
